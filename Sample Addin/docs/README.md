
# Sample AddIn for Inventor 2025

This example add-in shows the integration of the Ribbon Manager.
A custon tab is created and a panel for each of the following controls.

- Button CommandControl 
- ButtonPopup CommandControl 
- ComboBox CommandControl 
- Gallery CommandControl 
- Popup CommandControl 
- SplitButton CommandControl 
- SplitButtonMRU CommandControl (Most Recently Used)
- TogglePopup CommandControl
 
   


    

In addition, a slideout function has also been created for each panel.
  
The Sample Button also use a Progressive ToolTip.
